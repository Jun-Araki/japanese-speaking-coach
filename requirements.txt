# NOT WHAT STREAMLIT COMMUNITY CLOUD INSTALLS, which this file claimed until
# 2026-08-24. The build log says so plainly — it warns that more than one
# requirements file was found and installs from pyproject.toml and uv.lock, which is
# why ruff and uvicorn turned up in a deployment that names neither. The CPU pin
# below was therefore doing nothing there: the lock resolved torch from PyPI and
# brought cuda-toolkit and triton onto a machine with no GPU. pyproject.toml now
# points torch at the same index this file does, so the two agree; this file is what
# a `pip install -r` reads, and the Docker image is built from it.
#
# CPU TORCH, EXPLICITLY. `pip install torch` on Linux pulls the CUDA runtime with
# it — nvidia-cudnn, nccl, cusparselt, nvshmem and triton — which is roughly two
# gigabytes of GPU libraries for a free tier that has no GPU. The CPU index below
# gives the same torch at about a fifth of the size. Without this line the build
# does not fail with a helpful message; it fails on disk, minutes in.
--extra-index-url https://download.pytorch.org/whl/cpu
